Gamepad check

What this browser's navigator.getGamepads() returns, raw, for every pad.

A browser lists a pad only after a button on it was pressed with this page in front. To look for noise: press a button, let go, put the pad down, press Reset counts and wait ten seconds without touching it. A clean pad shows 0 changes everywhere; a changed count, in orange, is input nobody gave.
